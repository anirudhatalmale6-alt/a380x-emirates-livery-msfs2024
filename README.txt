Emirates A380-842 livery for the FlyByWire A380X - MSFS 2024
============================================================

WHAT THIS IS
Airbus A380-842 in Emirates colours, registration A6-EDY, painted on the
official FlyByWire A380X paintkit v0.3.

INSTALL
1. Close MSFS 2024.
2. Copy the folder "flybywire-aircraft-a380-842-livery-emirates-a6edy" into
   your Community folder, next to the "flybywire-aircraft-a380-842" folder.
   Typical Community folder locations:
     MS Store  %LOCALAPPDATA%\Packages\Microsoft.Limitless_8wekyb3d8bbwe\LocalCache\Packages\Community
     Steam     %APPDATA%\Microsoft Flight Simulator 2024\Packages\Community
   If you already know where your other add-ons live, it goes there.
3. Start MSFS 2024. The livery shows up under Airbus A380-842, variant
   "Emirates".

IF THE AIRCRAFT LOADS BUT THE PAINT DOESN'T SHOW
That is nearly always the texture filenames. The DDS files in TEXTURE.EK have
to be named exactly what the A380X model asks for. Send me a screenshot of the
file names inside:
   Community\flybywire-aircraft-a380-842\SimObjects\AirPlanes\FlyByWire_A380_842\TEXTURE\
and I will rename them to match and send it straight back. Nothing else in the
package has to change.

WHAT IS PAINTED
  Fuselage forward / mid / aft     gold Emirates titles, gold Arabic wordmark
  Tail                             UAE flag banding, red fin
  Rear fuselage and tailcone       red sweep
  Belly fairing                    red aft section
  Engines (all four)               gold wordmark on the outboard cowls
  Wingtip fences                   red
  Rear fuselage                    registration A6-EDY

WHAT IS NOT INCLUDED ON PURPOSE
The wings, pylons, gear doors and windscreen frame are left as the standard
FlyByWire textures, so the aircraft keeps all of its stock detail on those
parts. Only the sheets that actually change colour are replaced.

KNOWN LIMITATIONS
- The Arabic wordmark is set in a standard Arabic typeface, not the Emirates
  calligraphy, which is a custom drawn mark. Can be hand-drawn if you want it.
- The Latin "Emirates" is the closest typeface I could match; the real one is
  a commissioned custom face.
- Textures are BC1/DXT1 compressed with full mipmaps (verified in the file
  headers). BC7 would be a touch cleaner on the gold lettering, but the tool
  for it is Windows-only.
- Textures are 4096x4096. The paintkit is 8192; an 8K build is possible if you
  want it sharper up close, at roughly four times the file size.
